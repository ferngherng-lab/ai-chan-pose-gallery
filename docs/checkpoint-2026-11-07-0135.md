## 8. 已定案的設計決策（v6→v10，勿重開討論）

1. 分類「肉體(表情+頭髮)→形象，一切外在→服飾」。
2. 髮上飾品、尾/翼 → 服飾；僅耳/角頭部動物特徵存疑（暫歸服飾·其他）。
3. **停用槽位數量限制**（各部位多選，疊加層次）。
4. 關係＝**疊加／部分替換**；部分替換聚焦「形象錨點＋服飾高優先級」，形象/服飾**內部**部分替換暫擱置。
5. **借鑑原版**：服飾＝參考圖＋完整提示詞（`服装名称`+`标签`+`关键词`）。
6. aichan 配飾「名称＋參考圖」已足，**無需補 `关键词`**（關鍵詞欄位空是正常的）。
7. **退出策略**（開關展開子欄位，舊三元素邏輯零缺失）。

## 9. 踩過的坑 / 注意事項

- **中文 stdout 亂碼**：Git Bash 直接跑 Python print 中文會 mojibake；正確做法是寫 UTF-8 檔案再用 Read 工具讀。
- **讀取不可信資料**：跑任何會讀取下載資料的 Python 一律加 `-I`（隔離模式），避免工作目錄被種 `json.py` 等劫持 import。
- **憑證安全**：`cfat_` token 與 account id 永不列印；只用程式提取後當環境變數。
- **SFW 安全模式預設 ON**：18+ 內容靠 safe-mode 門禁，預設必須維持開啟。
- **分類 over-match**：早期用「耳/角」關鍵字誤抓耳墜/耳飾/四角星；已改成精確「狐耳/鳍耳/猫耳/兔耳/龙角」。
